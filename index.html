CONFIGURATION
Comma-separated. Say one of these to arm the console for a command.
Only the selected provider is called. You can switch brains without changing the rest of the console.
Keys are loaded automatically from api-keys.js. You can still temporarily override them here in Settings for the current browser tab.
WARNING: uploading real keys inside api-keys.js to a public GitHub Pages site exposes them to visitors. Use only for a private/personal setup.
STATIC MODE: requests go directly from your browser to the selected AI provider. Provider browser/CORS policies can change independently of ARC.
Each AI remembers its own voice. Leave a provider on AUTO to use the preferred Google voice when available, otherwise the browser's default voice.
When on, the console starts listening for the wake word again automatically after it finishes speaking.
Voice recognition uses the browser SpeechRecognition engine. Voice output uses Web Speech synthesis and preferentially selects a Google voice when Chrome/Edge exposes one. Microphone permission is still required exactly as before.
